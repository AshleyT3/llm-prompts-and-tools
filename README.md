# llm-prompts-and-tools

A growing collection of scripts and prompts for working more effectively with AI/LLM-related tools such as [Claude Code](https://claude.ai/code).

---

## scripts/

| Script | Description |
|--------|-------------|
| [`claude_to_markdown.py`](scripts/claude_to_markdown.py) | Convert Claude Code JSONL conversation history to browsable Markdown files |
| [`ollama_summarize_claude_markdown.py`](scripts/ollama_summarize_claude_markdown.py) | Summarize those Markdown sessions locally via [Ollama](https://ollama.com/) — one summary per session plus a consolidated digest |

See [`scripts/`](scripts/) for full documentation.
